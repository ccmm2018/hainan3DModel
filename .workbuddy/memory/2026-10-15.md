## 黑面优化（14:46 轮）⭐
- 用户反馈：模拟街区建筑「从某个方向看，有的面是黑色的」，观感不佳，需优化。
- 解析 GLB 材质（inspect_mat.py）拿到真因：
  - **`mat[70] 'Facade_Library' metalness=1.0`** —— 图书馆立面被误设为**纯金属**。高德 GLCustomLayer 多数环境是 WebGL1，PMREM/IBL 环境贴图生成失败、无环境可反射；金属漫反射为 0、反射又采不到环境 → 从多数角度纯黑（仅太阳高光一条亮）。这是"某些面/某栋楼发黑"的典型根因。其余楼栋 metalness 均为 0、基础色/贴图正常。
  - 场景灯光本已足够（Ambient 0.7 + Hemisphere 1.1 + Dir 2.0 + Fill 0.9），非金属于任何角度都不可能纯黑 → 锁定金属度异常 + 单面剔除/法线问题。
- **修复（MapScene.ts，纯代码、未动模型文件）**：
  1. 模型网格遍历里对每枚 `MeshStandardMaterial`：`metalness>0.5` 压到 `0.1`（消除金属黑）；`side` 改 `DoubleSide`（消除单面剔除导致"外看内侧空洞/背景"发黑——某些角度黑面最常见根因）。
  2. `setupLights`：半球光地面色 `#5a6472`(深蓝灰)→`#b3bcc9`(浅灰蓝)、强度 1.1→1.15，改善背光/底面发暗。
  3. 主方向光阴影相机：默认 ±5 正交视锥对 300+ 单位大场景太小，会错误压暗成暗斑 → 放宽到 ±500、far=1600、加 `normalBias=0.6 / bias=-0.0006`，并新增 `fitShadowToModel()` 在 `placeModelAtAnchor()` 后把光源 target 对齐到模型包围盒中心（模型放在 anchorWorld 远离原点，否则阴影视锥罩不到建筑）。
- vue-tsc 通过。仅改 JS，未改 GLB，故 `?v=` 无需升级；dev 热更即可，生产需重新 `npm run build`。
