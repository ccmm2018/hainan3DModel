# 2026-10-08

## 修复 FloorPlan2D 编辑模式「拖动房间可换位置」无效

- 现象：编辑楼层(房间)模式下拖动房间没有任何效果（提示与实际不符）。
- 复现/定位：用 playwright-cli + 系统 Chrome 端到端测试（IndexedDB 种子楼层+房间数据）。
  - 楼层有真实入库房间时拖拽正常；
  - 楼层存在但无入库房间（显示 12 个演示房间 demo_0~demo_11）时拖拽完全无效。
- 根因：`roomBlocks` computed 中演示房间分支忽略 `gridPos`，永远按 `idxToSpan(idx)` 渲染，
  而 `applySpan` 只改 gridPos → 画面不动。
- 修复（均在 src/components/FloorPlan2D.vue）：
  1. roomBlocks 渲染统一 `gridPos[room.id] ?? idxToSpan(idx)`；
  2. 新增 `syncDemoGridPos()`：无真实房间时把演示房间也铺入 gridPos；有真实房间时清掉 demo_* 键（避免幽灵占格）；
  3. `rebuildGrid()` 末尾调用 syncDemoGridPos；
  4. `commitSpan()` 对 `demo_` 前缀房间直接跳过（合成数据不入库）；
  5. 编辑模式提示语按 `hasRealRooms` 动态：真实房间=原提示；演示预览=「仅本次浏览生效，导入图纸后编辑真实房间才会保存」。
- 验证：演示模式 movedDx 0→148；真实房间回归通过；vue-tsc 零错误；floorRoom.spec.ts 11 测试全过。
- 测试环境备忘：playwright-cli 的 browser session 在两次 Bash 调用之间会被回收 → 必须把 open+操作+断言串在同一条 bash 命令里；snapshot --filename 输出在项目根目录而非 .playwright-cli/。
